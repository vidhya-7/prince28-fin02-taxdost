# Real user questions: TaxDost

Written the way my user types them. User: First-job software engineer in Chennai earning about Rs 9 lakh a year, filing an income tax return for the first time.

These 10 questions become my first evaluation set in Week 3. Question 6 is not answerable from my documents: the product must say "I don't know".
